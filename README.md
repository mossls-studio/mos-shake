# mos_shake — EffectCraft 抖动效果

手持感抖动：噪声驱动的位移 + 旋转（可开 X/Y/Z 三轴）、频率与平滑度独立可调、
8 采样运动模糊、拼贴边缘。像素级效果，直接改写图层画面，**不写图层的变换属性**。

| 项目 | 值 |
| --- | --- |
| 效果 ID | `mos.shake` |
| 显示名 | mos_shake |
| 分类 | MOS |
| 版本 | 1.1.0 |
| 作者 | MOSSLS |
| 插件 ABI | 1（WebAssembly） |
| 平台 | EffectCraft 桌面版、effectcraft-cli；不支持 Web 版 |

## 安装

插件包 = `mos_shake.wasm`（单文件，无依赖）。

1. **安装（推荐）**：Effect ▸ Install Effect Plug-in… 选 `dist\mos_shake\mos_shake.wasm`，
   文件会被复制进 `%APPDATA%\EffectCraft\Plug-ins`，之后每次启动自动加载。
2. **临时加载**：Effect ▸ Load Effect Plug-in… 选 `.wasm`，只对当前会话有效。
3. **命令行**：
   `effectcraft-cli script --eval "app.run('effect.plugins.load', {path: '…\\mos_shake.wasm'})"`

卸载 = 删掉 `Plug-ins\mos_shake.wasm`。同名插件不会覆盖，换版本前先删旧文件。

## 参数

| # | 参数 | id | 类型 | 默认 | 范围 | 说明 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | 抖动幅度 | `amplitude` | slider | 20 | 0 – 300 px | 位移的最大偏移量（图层像素，随渲染缩放） |
| 2 | 抖动频率(Hz) | `rate` | slider | 2.5 | 0.05 – 30 | 每秒改变方向约多少次，越大越急促 |
| 3 | 抖动平滑度 | `smoothness` | slider | 60 | 0 – 100 % | 0 = 匀速折线（硬拐点），100 = 完全缓入缓出（飘） |
| 4 | 抖动的旋转度 | `rotation` | slider | 1.5 | 0 – 45° | 画面内旋转（Z 轴）的最大角度 |
| 5 | 三轴旋转 X/Y/Z | `rot3d` | checkbox | 关 | — | 打开后额外叠加 X / Y 轴摆动（带透视），角度 = 旋转度 × 2，上限 43° |
| 6 | 运动模糊 | `motion_blur` | checkbox | 关 | — | 按 1/60 s 快门把若干子采样帧平均起来 |
| 7 | 拼贴模式 | `tile` | checkbox | 关 | — | 越界像素重复画面边缘；关闭时越界透明 |
| 8 | 模糊采样数 | `blur_samples` | slider | 8 | 1 – 8 | 运动模糊的子采样数：8 = 最顺滑，4 = 快一倍，1 = 不模糊 |

幅度与旋转度都为 0 时效果直接跳过（返回原图，不产生开销）。

## 用法建议

- **整段画面一起抖**：把效果加到**调整层**（Layer ▸ New ▸ Adjustment Layer）上，
  调整层会把下面的所有图层合成后再抖，并且不会裁掉任何内容。
- **只抖某个图层**：直接加在该层上。注意效果只能在图层自己的像素范围内搬动画面，
  文字/形状层的缓冲就是它的包围盒，幅度开大时边角会被图层边界切掉——这时把幅度
  调小，或改用调整层。
- **拼贴模式**适合素材层（照片、纹理、全屏素材）：抖动后越界的位置重复画面边缘，
  不会露出透明边。关掉拼贴则越界透明，适合需要透出下层的情况。
- 参数全部是静态值，不加关键帧也能动——时间就是动画，勾了效果就有连续抖动。

## 算法

**1. 噪声（无外部依赖）。** 时间是唯一输入，用整数哈希 + 值噪声：
`hash(ch, i)` 走 xorshift 风格混合，`noise(ch, t, T)` 在 `T` 秒一个格子里做插值，
再叠两倍频（0.37× 周期，权重 0.28）做出轻微细节。5 条独立通道
（X 位移、Y 位移、Z 旋转、X 旋转、Y 旋转）互不相同、可复现。

- 频率：`T = 1 / rate`。
- 平滑度：插值在 `f`（线性）与 `6f⁵−15f⁴+10f³`（quintic 缓动）之间按
  `u = f + smoothness·(quintic − f)` 混合。所以频率决定「多快」，平滑度决定
  「每个拐点多圆」，二者互不干扰。

**2. 变换。** 全帧反向映射：对每个输出像素求它在原图里的位置，再双线性采样。
旋转用 `R = Rz·Ry·Rx`；3D 开关关掉时 `Rx = Ry = 0`，退化成纯平面旋转。
透视投影用针孔近似的平面单应：

```
n  = R · e3
den = n₁·sx + n₂·sy + n₃·D          D = 3·max(w, h)
u  = (a₁₁·sx + a₁₂·sy) / den + cx
v  = (a₂₁·sx + a₂₂·sy) / den + cy
```

`a` 的四个分量由 `R` 与 `D` 展开，`den ≤ 1e-4`（极端角度下平面穿过镜头）时输出透明。
位移就是 `sx = x − (cx + tx)`，与旋转在同一遍里完成。

**3. 运动模糊。** `k = 0..n−1`（`n` = 模糊采样数，1–8），子采样时间
`tᵢ = t + ((k + 0.5)/n − 0.5) · (1/60)`，每帧重算变换并累加，最后除以 `n`。
快门固定 1/60 s（约等于 30 fps 下 180° 快门）；帧率更高时模糊会显得更短。
采样数越少越快，4 个采样约等于一半开销，快速运动时可能出现轻微重影。

**4. 边界。** 开启拼贴时对源坐标做 `((i mod n) + n) mod n`，画面无限重复；
关闭时越界写 premultiplied 透明黑（RGBA 全 0）。

## 性能

宿主用 **wasmi 解释器**执行插件 WASM（带燃料计量的解释执行，不是 JIT）。同一份内核在
Node/V8 里 1080p 约 40 ms，在 EffectCraft 里约 500 ms——解释器大约慢 13 倍。这是所有
第三方 wasm 插件共用的运行时，也就是所谓「翻译层」的真实含义；实测同类第三方
Marsel Shake 在相近参数下 1.24 s/帧，比本插件还慢一倍。另外这个运行时**禁用了 SIMD**：
模块里只要出现 `v128` 指令就直接加载失败（`unexpected SIMD opcode: 0xfd`），所以只能
靠减少逐像素指令数来提速。

1920×1080 实测（`effectcraft-cli` headless，单帧 `comp.saveFrameAs` 墙钟，已扣除启动
与 PNG 编码基线约 110 ms）：

| 设置 | 内核每帧 |
| --- | --- |
| 幅度 34 + 旋转 1.4° | 503 ms |
| 再加三轴旋转 | 575 ms |
| 再开拼贴 | 524 ms |
| 运动模糊 8 采样 | 4.7 s |
| 运动模糊 4 采样 | 2.5 s |

对照 1.1.0 旧版（3755 B，之前装着的那份）同样测法：2.12 s / 16.1 s——本版内核快约 4 倍。
Marsel Shake 同参数 1.24 s/帧。

**预览建议。** 100% 分辨率下每个像素都要过一遍解释器，1080p 想流畅基本不现实；最有效的
办法是把播放分辨率降到 50%（像素数 1/4）或 25%（1/16），其次是关掉运动模糊、或把
「模糊采样数」调到 4。拼贴与三轴的开销和普通位移接近，不必为了性能刻意关掉。

## 开发

```powershell
npm install                  # 只依赖 wabt
node build.js                # 编译 → dist\mos_shake\mos_shake.wasm
node tools\test_wasm.js      # 21 项自测，样张写到 build\out\
```

自测覆盖：参数直通、噪声位移与 JS 参考实现逐像素一致、旋转中心不动、
3D 质心与参考投影一致、单应往返（正向(反向(p)) ≈ p，误差 0 px）、
拼贴覆盖率、运动模糊质心 = 快门子采样均值、频率对速度的影响、
平滑度对缓动的影响、确定性、scale 无关性。

## 已知限制

- 效果只改像素，**不动图层的位置/旋转关键帧**。想保留可编辑的原生变换，
  需要用 ScriptUI 面板脚本把同样的噪声写成关键帧（另一条路线，本插件不含）。
- 3D 是平面单应投影，没有真实几何厚度；极端角度下边缘会被透视裁掉。
- 运动模糊是固定 8 采样 + 固定 1/60 s 快门，不随合成帧率变化。
- 越界区域的拼贴是无限重复，不做镜像。
